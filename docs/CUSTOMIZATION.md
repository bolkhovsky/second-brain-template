# Персонализация Second Brain

## Манифест — ваша философия

Файл `_brain/prompts/manifest.md` — это сердце системы. Манифест определяет:
- Тон и стиль рекомендаций агента
- Приоритизацию задач и целей
- Критерии принятия решений
- Философию работы с временем и энергией

---

## Структура манифеста

### Минимальная версия

```markdown
# Second Brain Agent

## Роль
Ты — персональный стратегический ассистент ("Второй мозг").
Управляешь фокусом владельца хранилища, помогаешь визуализировать цели и двигаться к ним.

## Мой манифест

[Ваш текст здесь — 2-5 абзацев о вашей философии]
```

### Расширенная версия

```markdown
# Second Brain Agent

## Роль
Ты — персональный стратегический ассистент ("Второй мозг").
Управляешь фокусом владельца хранилища, помогаешь визуализировать цели и двигаться к ним.

## Мой манифест

### Философия
[Ваши убеждения о работе, жизни, бизнесе]

### Принципы
- Принцип 1
- Принцип 2
- Принцип 3

### Ограничения
[Что для вас неприемлемо, какие границы важны]

### Вдохновение
[Авторы, методологии, подходы которые вам близки]
```

## Примеры манифестов

### Предприниматель

```markdown
## Мой манифест

Я строю бизнес вокруг свободы: своей и клиентов. Деньги — инструмент, 
не цель. Масштаб имеет смысл только если улучшает качество жизни.

Работаю 12-недельными спринтами с чёткими метриками. Отдых — часть 
системы, не награда. Говорю "нет" чаще чем "да".

Продажи — это помощь в принятии решений, не манипуляция.
```

### Разработчик

```markdown
## Мой манифест

Код — это коммуникация. Пишу для людей, не для машин.
Простота > сложность. Работающий код > идеальный код.

Фокусируюсь на одной задаче за раз. Измеряю прогресс 
shipped features, не часами работы.

Deep work утром. Meetings после обеда. Вечер — для жизни.
```

### Творческий специалист

```markdown
## Мой манифест

Творчество требует пустоты. Заполненный календарь — 
враг идей. Скука — ресурс, не проблема.

Показываю работу до её совершенства. Feedback > 
изоляция. Сделанное > идеальное.

Энергия важнее времени. Слежу за состоянием, 
не за расписанием.
```

## Влияние манифеста на агента

### Тон рекомендаций

**Если в манифесте:** "Stoic-подход, спокойствие в турбулентности"

**Агент будет:** давать рекомендации без паники, фокусироваться на зоне контроля

### Приоритизация

**Если в манифесте:** "Свобода основателя важнее масштаба"

**Агент будет:** предлагать делегирование, автоматизацию, отказ от low-leverage задач

### Интервенции

**Если в манифесте:** "Отдых — часть системы"

**Агент будет:** напоминать о восстановлении, не предлагать "дожать" через усталость

## Настройка целей (state.json)

### Структура цели

```json
{
  "goal_id": {
    "name": "Читаемое название",
    "target": "Конкретный, измеримый результат с дедлайном",
    "current": "Текущее состояние",
    "progress_percent": 0-100,
    "trend": "positive | stable | at_risk",
    "last_action_date": "YYYY-MM-DD",
    "notes": "Дополнительный контекст"
  }
}
```

### Примеры хороших целей

```json
{
  "book_launch": {
    "name": "Запуск книги",
    "target": "Опубликовать на Amazon, 100+ продаж за первый месяц",
    "current": "Черновик готов, редактура в процессе",
    "progress_percent": 60,
    "trend": "positive",
    "last_action_date": "2026-01-15",
    "notes": "Дедлайн: 1 марта. Редактор заканчивает 20 января."
  }
}
```

### Количество целей

Рекомендуется 2-4 цели на квартал:
- 1-2 критические (🔴)
- 1-2 важные (🟡)

Больше 4 целей → размывание фокуса.

## Настройка паттернов

```json
{
  "patterns": {
    "productive_days": ["Wednesday", "Thursday"],
    "low_energy_days": ["Monday", "Sunday"],
    "avg_tasks_per_day": 3,
    "strategic_ratio": 0.3,
    "common_blockers": [
      "позднее начало дня",
      "много встреч",
      "реактивная работа"
    ]
  }
}
```

Агент использует паттерны для:
- Адаптации рекомендаций под день недели
- Обнаружения отклонений от нормы
- Предложений по улучшению продуктивности

## Расширение системы

### Добавление новых секций в брифинг

Отредактируйте `_brain/prompts/base.md`:
1. Найдите секцию "Формат секции брифинга"
2. Добавьте новую секцию в шаблон
3. Добавьте логику генерации в алгоритм

### Новые типы интервенций

В `base.md` найдите таблицу "Типы интервенций" и добавьте:

```markdown
| Условие | Тип | Сообщение |
|---------|-----|-----------|
| [ваше условие] | `CUSTOM_TYPE` | [действие] |
```

### Интеграция с внешними сервисами

Для cloud-режима (Нодуль) добавьте новые HTTP Tools в `cloud.md`.
